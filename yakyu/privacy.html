制作ツール「野球動画アップロード」

このツールについて

「野球動画アップロード」（以下「本ツール」）は、YouTube チャンネル「野球ニュース深掘り便」の運営者が、自分で制作した動画を自分のチャンネルに非公開でアップロードするためだけに使う制作ツールです。運営者本人のパソコンの中で動き、ほかの方に提供するサービスではありません。

使う Google のデータと目的

本ツールは、運営者本人が許可した次の YouTube の権限だけを使います。

  • YouTube への動画のアップロード（youtube.upload）：制作した動画を非公開でアップロードし、サムネイルを設定するため
  • YouTube アカウントの管理（youtube.force-ssl）：アップロードした動画に字幕を設定するため。アップロードした自分の動画の処理の状況（サムネイルを設定してよい状態になったか）と、再生回数などの数字を確かめるため

読み取るのは運営者自身のチャンネルと動画の情報だけです。再生回数などの数字は、運営者が自分の動画の作り方を見直すためにだけ確かめます。

これ以外の目的（広告、他のサービスへの提供など）には使いません。動画の公開・削除や、コメント・登録者の一覧・視聴履歴などの取得は行いません。

保存と共有

  • 許可の情報（アクセストークン）は、運営者のパソコンの中に、本人だけが読める設定で保存します。外部のサーバーには送りません
  • Google から受け取ったデータを、第三者に販売・共有・譲渡しません
  • Google から受け取ったデータを、AI・機械学習のモデルの学習に使いません。学習のために他社へ提供することもありません
  • 運営者が自分の動画の数字を整理するときに、AI アシスタントを作業の道具として使うことがあります。その場合も運営者のための作業にだけ使い、上の取り扱いを守ります

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

許可の取り消し

許可はいつでも、Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。取り消すと、本ツールは YouTube にアクセスできなくなります。運営者のパソコンに保存した許可の情報も、そのときに削除します。

お問い合わせ・変更

このポリシーについてのお問い合わせは、YouTube チャンネル「野球ニュース深掘り便」までお寄せください。内容を変える場合は、このページを更新します。
